# 移动端、沙堆与性能：本次尝试

本次修改针对手机读数方向、观察视角、沙堆形状与低帧率。没有真实手机参与自动测试，桌面结果不能代替用户手机上的 20 FPS 问题验收。

## 已保留的改动

- 以粗指针设备识别手机和平板：默认反向传感器读数，校准菜单仍可手动切换。
- 手机使用正面固定相机，关闭环绕、缩放与平移；双击复位仍保持正面。桌面保留原有操作。
- 手机默认 1000 粒，像素比上限从 1.6 降为 1，自动恢复画质也遵守这个上限。没有降低物理步频或删除沙粒。
- GPU 速度重建合入速度接触求解，预测与首轮网格插入合并。每个子步的 dispatch 从 15 次降到 13 次，固定外步从 120 次降到 104 次。
- 网格仍在每轮修正前重建，但只清空上一轮被粒子占用的格子。每粒保存一个格子索引，额外占用 4 字节；同一格子的重复清空使用原子写入。重置时清空整个网格。空链表使用零初始化编码，没有丢弃邻居或限制桶容量。
- 性能面板直接显示 GPU 尚未实现休眠，避免让“未回读”掩盖这个事实。

## 沙堆临界角：未解决，停止扩大尝试

查阅了 [Macklin 等人的 Unified Particle Physics，第 6.1 节](https://mmacklin.com/uppfrta_preprint.pdf)。论文通过位置级的库仑静摩擦与动摩擦形成颗粒堆积；当前 CPU 和 GPU 求解器已经采用相同类别的方法。论文不是可以直接接入本项目的 WGSL 沙堆实现。

有限实验：在下腔放置 2253 个不重叠、交错密排的球形粒子，组成初始高约 12.34 mm 的圆锥，关闭空气阻力，推进 3 秒；比较最小与最大摩擦材料。另试将 GPU 接触迭代次数从 3 加到 6。全部保留相同步长，不靠冻结粒子、增添黏性或修改重力维持形状。

| 材料 | 原求解器最终堆高 | 6 次迭代最终堆高 | 最终保留的调度优化后堆高 |
|---|---:|---:|---:|
| 极细沙 | 6.54 mm | 10.10 mm | 5.56 mm |
| 高摩擦晶体 | 8.63 mm | 7.76 mm | 9.39 mm |

6 次迭代时两种材料的 GPU 步耗时约 3.84 / 4.01 ms，原始实验约 3.28 / 0.95 ms。堆高变化没有一致改善，计算成本却上升，因此撤回迭代次数修改，保持 3 次。

这些数字只描述预制圆锥的塌落，**不是测得的休止角**，也不能证明自然落砂可形成正确的临界角。并行原子插入顺序会改变接触累加顺序，单次堆高不能作为材料标定。可靠改进可能涉及接触载荷历史、收敛策略或颗粒转动等，需要更系统的验证；本次按有限尝试的约定停止，没有宣称修复。

## 1000 粒与静止后的性能：仅有小幅改善

参考 [Apple 的 WebGPU 性能建议](https://developer.apple.com/videos/play/wwdc2025/236/)，检查计算资源、命令提交和同步开销。最终保留的合并计算与占用格清理由现有实现推导，没有照搬其他设备的帧率。

环境为 Linux、Chromium、NVIDIA Blackwell 硬件 adapter，非软件 GPU。将原本上腔的 1000 粒初始分布镜像到下腔，诊断容器统一使用 3.15 mm 喉径，关闭空气阻力，推进 720 个固定步（6 秒）。这是独立求解器微基准，未运行整页渲染。表中是异步 GPU 时间戳的最近完成批次采样中位数，每批推进一个固定步，**不含绘制，不等于 FPS**。

| 指标 | 修改前 | 修改后 |
|---|---:|---:|
| 前 120 步 GPU 耗时中位数 | 0.952 ms | 0.932 ms |
| 后 120 步 GPU 耗时中位数 | 0.961 ms | 0.943 ms |
| 最终粒子 RMS 速度 | 0.037 mm/s | 0.057 mm/s |
| 有限性错误 / 越界数 | 0 / 0 | 0 / 0 |

接近静止后仍要执行全部接触计算。GPU 路径没有休眠，CPU Worker 路径才有支撑链休眠。优化后的晚期耗时约减少 1.8%，属于小幅变化，单次比较不能排除运行波动；不能声称已解决手机低帧率。手机像素密度与启动粒子数改动另行减少绘制负担，但没有实机帧率数据。

没有加入简单的低速冻结：低速不代表有稳定支撑，错误冻结会让悬空沙粒不再下落，或在倾斜手机时无法正确唤醒。

原始记录：[修改前](../benchmarks/performance-baseline.json)、[修改后](../benchmarks/performance-occupied.json)。

## 验证与已知问题

- 57 项单元测试、TypeScript 检查与生产构建通过。
- CPU 和 WebGPU 浏览器测试通过，包括权限、传感器输入、暂停、重置、材料/空气切换、数量变更和 GPU 设备丢失报错。
- 移动端浏览器模拟检查通过：反向默认值、1000 粒、像素比上限、触摸拖动/双击/横竖屏不改变视角及无横向溢出。截图来自实际运行页面。
- 最终 GPU 5000 粒烟雾测试通过：完整推进 360 步，持续过颈、反向加速度、无越界、状态有限，抽样最大重叠约 32%。但修改前同一测试曾出现约 37% 重叠，超过现有 35% 检查线。并行求解存在运行波动，最终一次通过不代表已经修好接触压缩。
- 未验证真实 Android/iPhone 的极性、持续帧率、功耗或传感器唤醒；没有新增 GPU 休眠。
