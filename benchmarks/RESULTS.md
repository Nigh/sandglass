# 当前实测与验收

## 5000 粒实时模拟

实际生产包通过 `vite preview` 运行。环境：Linux x64、Intel Core Ultra 7 265K、NVIDIA GeForce RTX 5060 Ti、Chromium 156、Node v24.9.0。WebGPU adapter 为 `nvidia / blackwell`，`isFallbackAdapter=false`；不是 SwiftShader。

```sh
BASE_URL=http://localhost:5178 npx tsx scripts/realtime-benchmark.ts
```

1280×900、像素比 1；固定 5000 粒，依次运行向下 1g、翻转 1g、横向 2g、0g、恢复向下 1g。原始逐帧数据：`realtime-5000.json`。已清理本次诊断浏览器负载；没有终止用户原有 GPU 应用，因此不是独占 GPU 基准。

| 指标 | 实测 |
|---|---:|
| 墙钟时长 | 60.0075 s |
| 实际绘制帧数 | 3601 |
| 平均绘制帧率 | 60.002 FPS |
| 帧间隔 P50 | 16.7 ms |
| 帧间隔 P95 | 16.9 ms |
| 帧间隔 P99 | 17.0 ms |
| 窗口内实际物理外步 | 7200 |
| 窗口内实际模拟时间 | 60.0000 s |
| 丢弃模拟时间 | 0 s |
| 窗口结束积压 | 14.33 ms |
| 最大积压 | 16.83 ms |
| CPU 物理编码/提交 P95 | 0.200 ms |
| GPU 整批物理 P50 | 9.962 ms |
| GPU 整批物理 P95 | 10.379 ms |
| GPU 整批物理 P99 | 10.412 ms |

帧间隔来自两次实际绘制提交，不是单纯统计 `requestAnimationFrame` 回调。物理进度与墙钟分别核对，不能靠冻结沙粒或丢弃模拟时间换取高帧率。GPU 时间来自 timestamp query，是最近完成的整批计算，不是每个固定步的耗时，也不包含绘制；CPU 提交时间没有冒充 GPU 时间。

GPU 每个 1/120 秒外步使用 8 子步、每子步 3 轮位置接触求解。每批最多提交两个外步，避免大批追赶导致持续低帧率；未提交时间留在可见积压中。60 Hz 绘制时最多推进 120 Hz 物理，短暂停顿的积压不会被额外步骤追平。

## 形状、半高与细流

内高 86 mm、最大内径 50 mm，采用自然短喉口双曲锥面，渲染与碰撞共用几何。5000 粒孔径 3.15 mm，基准等效半径 0.420 mm，最大直径约 0.995 mm。初始化顶面 23.1547 mm，占上腔高度 53.848%；不是悬空半层或相互穿插的初始分布。

GPU 显式验收推进 360 个固定外步，读取状态仅用于检查：

| 模拟时间 | 下仓粒数 | 非有限分量 | 边界违反 | 抽样最大穿透/直径 |
|---|---:|---:|---:|---:|
| 0 s | 0 | 0 | 0 | 0 |
| 1 s | 119 | 0 | 0 | 0.265 |
| 2 s | 210 | 0 | 0 | 0.248 |
| 3 s | 305 | 0 | 0 | 0.211 |

原始数据：`gpu-smoke.json`。反向重力、关闭空气后的上移也通过。接触是有限迭代的粗粒体积采样，仍有可测压缩；不是解析真实微粒、转动与棱角的精确 DEM。不用固定流速、计时放粒、删除颗粒或强制解堵维持沙流。

实际生产帧：`initial-5000.png`、`flow-5000.png`、`mobile-5000.png`，覆盖初始半高、窄束下落与 390 px 手机视口。移动布局没有横向溢出；不代表真实手机 GPU 或传感器已验收。

旧几何的 97 秒排砂实测及其时长外推已经失效，界面估时已删除。历史 `flow-1000-final.json`、`flow-short.json`、`browser.json`、`physics.json` 不作为新几何的流量或加速比证据。

## 实现依据

参考用户提供的 [grain-cuda-sand](https://github.com/SamG-Coder/grain-cuda-sand)：GPU 常驻状态、计算/渲染共用缓冲、预分配资源、局部网格邻域、无竞争 Jacobi。没有引入其 CUDA 编译器，也没有照搬会截断惯性的位移上限。5000 粒采用无桶容量上限的原子链式 GPU 分桶，每轮位置修正前重建；CPU 兼容路径采用连续计数网格。

其它依据：[Müller 空间网格](https://matthias-research.github.io/pages/tenMinutePhysics/11-hashing.pdf)、[Small Steps](https://mmacklin.com/smallsteps.pdf)。论文和参考项目的性能数字没有当成本项目跑分。

正常 GPU 路径只上传标量参数，不读取粒子位置，也不逐帧重建 CPU 实例矩阵。可选计时异步读取 16 字节；显式物理验收才读取粒子快照。实例旋转只作用颗粒自身，不能旋转 GPU 世界中心；真实 GPU 目标像素回归覆盖这个边界。

## CPU 兼容路径

```sh
npm run benchmark -- --counts=5000 --seconds=12 --output=benchmarks/physics-current.json
```

最终 CPU 参数保留静摩擦、支撑休眠及足够位置收敛。12 秒墙钟涵盖向下堆积、0g、连续翻转、高幅值与反向堆积。它测的是 Worker 使用的求解器，不包含 Worker 传输或绘制。

| 5000 粒 CPU 指标 | 实测 |
|---|---:|
| 外步平均耗时 | 28.659 ms |
| 外步 P50 | 22.035 ms |
| 外步 P95 | 50.522 ms |
| 外步 P99 | 146.981 ms |
| 全状态采样次数 | 34 |
| 非有限分量 / 边界违反 / 半径变化 | 0 / 0 / 0 |

**CPU 回退没有达到 5000 粒 60 FPS。** 无 WebGPU 时保留真实 CPU 兼容功能并通过启动测量选择保守粒数，不冒充 GPU，也不承诺相同吞吐量。新旧几何与求解参数不同，不用旧数据计算虚假的独立算法加速比。

## 工程验收与剩余边界

- 57 项单元测试通过；TypeScript 检查与生产构建通过。
- CPU 与 WebGPU 浏览器验收均通过：启动锁定、传感器/预设互斥、2g/0g、故障、暂停重置、材料/空气、数量重建、同值数量幂等、外观和手机布局。
- GPU 真实目标像素检查通过；非零粒子中心投影命中，错误位置没有粒子像素，避免“物理在容器内、渲染却飞出玻璃”。
- GPU 设备丢失显式停止并报错，没有静默替换成 CPU。
- 入口包约 1172.58 kB，gzip 315.80 kB；构建仍给出超过 500 kB 的警告，未隐藏。
- Android/iPhone 的真实传感器、持续 60 FPS、温升与功耗仍需实机检查。WebGPU API 存在不代表 adapter 可用或性能充足。
